ERSTE LEHREROBERFLAECHE - 0.2.0-dev

Noch keine eigenstaendige EXE. Bestehendes funktionierendes Python-/Godot-Projekt noetig.

1. Ordner lehreroberflaeche_update direkt in city_project ablegen.
2. In city_project ausfuehren:
   python .\lehreroberflaeche_update\install_update.py
3. Abhaengigkeiten ergaenzen:
   python -m pip install -r requirements-teacher.txt
4. Start:
   python teacher_app.py
   oder Start_Lehreroberflaeche.bat doppelklicken.
5. Godot-Programmdatei einmal in der Oberflaeche waehlen.
6. Foto waehlen -> Erkennen -> Kontrollbild pruefen -> 3D oeffnen.

Vorhandene Dateien in scripts/, cityviewer/, settings/ und output/ bleiben unveraendert.
Die Sicherung enthaelt Code und Konfiguration, keine vollstaendige Modell-/Fotosicherung.
output/layout.json muss zum verwendeten Druckblatt passen.
cityviewer/data/buildings.json ist der Katalog fuer Erkennung UND Viewer.
Keine automatische Erzeugung neuer Druckvorlagen.

Getestet: acht Backendtests, Python-Syntax, Installer am Testprojekt.
Nicht getestet: GUI im echten Fenster, Godot-Start, komplette Fotoerkennung, Windows/Surface.
Testumgebung hier: Tk-Laufzeit fehlt; OpenCV-Import scheitert an fehlender libGL.so.1.
Der Subprozesstest nutzt einen kuenstlichen Testdetektor, keine echte Erkennung.
